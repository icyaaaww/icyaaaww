## About Me

我做 MoonBit 开发工具和 AI 编程插件，也会写代码做声音实验。

从 C 头文件生成绑定、找出表格中引用可疑的公式，到让 AI 找回会话里做过的决定，我喜欢把这些容易出错、难以回查的步骤变成工具。最近的声音实验是用雨声合成一套日语声库。
